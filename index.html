Наблюдение за переменными (Watch)

Что на линии: деталь едет по конвейеру (Motor1), доезжает до датчика (Sensor1 = вход, ставится автоматически, когда деталь физически стоит перед воротами) и ждёт у ворот (Gate1Open = выход). Кнопки ButtonStart/ButtonStop — обычные кнопки без фиксации, срабатывают только пока зажаты (как в реальном щите) — самоподхват нужно делать в коде. Lamp1 — сигнальная лампа, назначение придумай сам.

Программа (упрощённый Structured Text)

Синтаксис:
Присваивание: Переменная := выражение;
Логика: AND, OR, NOT, скобки, TRUE/FALSE
Условие: IF выражение THEN ... ELSE ... END_IF;
Таймер на включение: Var := TON(ИмяТаймера, условие, миллисекунды);
Комментарии: // строка или (* блок *)
Любое новое имя переменной — просто внутренняя ячейка памяти (для флагов, латчей и т.п.), объявлять не нужно.
