Теги (I/O)

Программа (упрощённый Structured Text)

Синтаксис:
Присваивание: Тег := выражение;   Логика: AND OR NOT ( ) TRUE/FALSE
Условие: IF выражение THEN ... ELSE ... END_IF;
Таймер (вкл. с задержкой): Var := TON(Имя, условие, миллисекунды);
Счётчик (нарастающие фронты): Var := CTU(Имя, условие, число);
Комментарии: // строка или (* блок *)
Имена тегов смотри в таблице «Теги (I/O)» слева — они появляются автоматически, когда на линии есть прибор. Любое незнакомое имя — просто внутренняя переменная-память (для флагов, латчей и т.п.).
